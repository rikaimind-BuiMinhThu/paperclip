# Value Proposition Design

## Trigger

## Required inputs

2. Do not activate campaigns or spend.
3. Save `marketing_strategy.md`, `campaign_plan.json`, `budget_plan.json`, `kpi_definition.json` as applicable.
4. Hand off to Manager `approval-management` for human confirmation of `marketing_strategy`.
